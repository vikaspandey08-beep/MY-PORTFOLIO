Vikas Pandey — Portfolio Website

A personal portfolio website built to showcase my skills, projects and journey as a Java Full Stack Developer. Designed with a modern dark theme, smooth animations and a fully responsive layout that works across desktop, tablet and mobile.

🔗 Live Demo: add your deployed link here (GitHub Pages / Netlify / Vercel)

✨ Features
Animated hero section with a typing effect that cycles through my roles
Smooth scroll navigation with an active-link indicator and scroll progress bar
Skill cards with animated progress bars
Project showcase cards with hover effects
Education timeline
Fully responsive design with a mobile hamburger menu
Contact section with clickable links to Email, Phone, GitHub, LinkedIn and Instagram
🛠️ Built With
HTML5 — semantic structure
CSS3 — custom properties, gradients, flexbox/grid, animations
JavaScript (Vanilla) — scroll effects, typing animation, IntersectionObserver-based reveal animations
📂 Project Structure
├── index.html      # Main markup
├── style.css       # Styling and animations
├── script.js       # Interactivity (nav, typing effect, scroll reveal, skill bars)
└── README.md
